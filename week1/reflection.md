MySQL demonstrates the advantages of the database approach over traditional file-based systems because it organizes data in a structured and manageable way. Instead of storing student information in separate files that may contain duplicate or inconsistent data, a database allows information to be organized and accessed efficiently. MySQL also supports querying, which makes it easier to retrieve specific records, update information, and manage large amounts of data. Another important advantage is data security because access can be controlled through user accounts and permissions.
The DBA responsibility that would become relevant first when storing real student data is database security and access control. Student information may include personal and academic details that should not be accessible to everyone. A DBA must ensure that only authorized users can view or modify sensitive information. This responsibility helps protect student privacy and prevents unauthorized changes. Proper security also supports the reliability of the database because users receive access based on their roles and responsibilities.
